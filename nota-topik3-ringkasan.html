2. Perbandingan Sistem Production vs Consumption

🏭
Production
  • Hasilkan udara termampat
  • 10 komponen utama
  • Kompressor + Motor elektrik
  • Tangki + Air dryer + Filter
  • Fokus: bekalan angin bersih
  • Terletak di loji utama
🔧
Consumption
  • Guna udara termampat
  • 6 komponen utama
  • Air take-off + Service unit
  • Directional valve + Actuator
  • Fokus: kerja mekanikal
  • Terletak di titik penggunaan

4. Konklusi

🎯
Penyelenggaraan = Pelaburan

Sistem bersih & teratur → kurang kerosakan → produktiviti tinggi
Abaikan penyelenggaraan → komponen cepat haus → kos pembaikan tinggi

💧
Buih Sabun = Alat Paling Murah

Buih sabun adalah cara paling murah dan berkesan untuk mengesan kebocoran udara. Wajib ada dalam setiap set alat penyelenggaraan pneumatik.

🔀
Memory Valve = Penyelesai Signal Overlapping

Signal Overlapping adalah masalah biasa pada DCV sistem pneumatik. Memory valve mengasingkan aliran udara supaya valve beroperasi tanpa gangguan dari kiri atau kanan.

5. Penekanan untuk Industri Sebenar

5.1 Keselamatan (Safety First)

⚠️
Tekanan Sisa

Sebelum servis, pastikan tekanan dilepaskan sepenuhnya. Udara termampat boleh menembusi kulit.

🔒
Lock Out Tag Out (LOTO)

Matikan punca kuasa, kunci suis, dan tag sebelum buka sistem. Elak kejadian tidak diingini.

🦺
Alat Pelindung Diri (PPE)

Guna cermin mata, sarung tangan, dan kasut keselamatan semasa bekerja dengan sistem bertekanan.

🔥
Suhu Tinggi

Selepas pemampatan, udara menjadi panas. Berhati-hati dengan permukaan panas kompressor & paip.

5.4 Masalah Biasa di Industri

Masalah Punca Cara Atasi
Kebocoran udara Seal haus, sambungan longgar Ganti seal, ketatkan sambungan, guna white tape
Valve tersekat Kotoran, karat, minyak berlebihan Servis dengan compressed air, pasang penapis
Signal Overlapping DCV sistem pneumatik Tambah Memory Valve
Tekanan tidak stabil Regulator rosak, bekalan tidak cukup Laraskan regulator, periksa kompressor
Silinder bergerak perlahan Kebocoran dalaman, seal haus Ganti seal, periksa flow control valve
Bunyi bising Ekzos udara, komponen haus Pasang penyeyap, servis komponen
